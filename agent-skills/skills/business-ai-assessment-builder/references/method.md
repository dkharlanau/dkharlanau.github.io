# Method

Start from a coverage gap, not from a random SAP topic. Define the Lead decision and the cross-domain tension first, then select only the SAP Enterprise and Business AI evidence needed for that case.

Create a duplicate fingerprint from process, stage, decision type, integration boundary, authority level, and main failure pattern. If an existing case has the same fingerprint, improve or vary it instead of adding a near duplicate.

The blind prompt contains only candidate-visible evidence. The hidden layer contains challenge points, scoring anchors, hard-fail signals, and follow-up logic. Score reasoning, ownership, controls, trade-offs, evidence handling, and communication separately from factual recall.
