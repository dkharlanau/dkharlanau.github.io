# Method

Start with the business job and a baseline. Select the smallest useful authority; use AI for ambiguity and deterministic software for authorization, validation and state transitions.

The six decisions are value and scope, identity and boundaries, access and authority, workflow governance, economics, and evidence and learning. Identity changes can alter all downstream controls. Evidence is a launch prerequisite and a feedback loop.

For each change, ask what changes for the actor, data, audience, tool permissions, budget, support and audit. A new shared channel or service identity may create a new trust boundary even with the same model. Verify overlapping roles, revocation, runtime policy and source-system permissions.

Compare options, record reversibility, and require an accountable owner. Test a negative path, not only the happy path. Reassess whenever the workflow gains new reach.
