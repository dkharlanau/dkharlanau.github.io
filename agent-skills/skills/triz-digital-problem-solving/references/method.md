# Method

The method is built around contradiction, separation, system resources, system-shape options, and reversible experiments.

Start by removing the preferred solution from the problem statement. Name the useful function and the two useful properties in tension. Then test six separation operators: time, condition, context, system level, authority, and representation.

Before adding a new platform, scan existing resources: data, history, timing, unused structure, negative signals, human judgment, policy, permissions, compute, and attention. Generate materially different system shapes rather than vendor variants.

Allocate deterministic rules, workflow, events, retrieval, models, agents, and accountable human decisions according to uncertainty and authority. Finish with a falsifiable experiment that measures both the target improvement and the counter-effect.
