# Method

Use this chain:

`Outcome → Identity → Grain → Ownership → Rule → CR/Workflow → Activation → Distribution → Migration → Business Proof`

The most important question is grain. If a value means something different by plant, sales area, company code or purchasing organization, model that qualifier explicitly.

Keep four proofs separate:

1. Governance proof: the right authority approved the right scope.
2. Activation proof: the intended value became active truth.
3. Distribution proof: the intended consumer accepted and persisted it.
4. Business proof: the process actually used it.
