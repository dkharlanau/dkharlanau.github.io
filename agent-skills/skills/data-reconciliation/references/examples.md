# Examples

## CSV export versus target load

A source extract contains 100,240 rows and the target contains 100,110. First confirm that both use the same date range and business filters. Validate the key and classify the 130-row difference as source-only, target-only, duplicate, filtered, or transformed before examining individual rows.

## Migration validation

Customer records are migrated from a legacy platform. Counts match, but country and tax fields differ. Compare approved mapping rules, identify whether the difference is expected transformation or a mapping defect, and rerun the same checks after correction.

## Management report

Two reports show different revenue totals. Confirm currency, posting date logic, status filters, aggregation grain, and late-arriving transactions before treating the difference as a calculation error.
