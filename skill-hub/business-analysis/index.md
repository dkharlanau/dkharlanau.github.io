  <p class="eyebrow">Skill Hub — Business Analysis</p>
  <h1>Turn ambiguity into structured, actionable requirements.</h1>
  <p class="lead">Skills for eliciting needs, mapping stakeholders, analyzing processes, finding gaps, defining acceptance criteria, and discovering business rules. Usable on enterprise, SAP, and data projects.</p>
</section>

<section class="section">
  <header class="section-heading">
    <h2>What this group covers</h2>
  </header>
  <p>Business Analysis skills help you work with ambiguity. They provide structured methods for understanding what stakeholders actually need, how work actually happens, what is missing, and how to verify that a solution is correct.</p>
  <p>These skills are cross-domain. They apply to SAP implementations, data governance initiatives, integration projects, process redesign, and operational improvement.</p>
  <p>Each skill page includes: a working method, diagnostic questions, decision rules, artifact templates, quality checklists, and specific instructions for AI agents.</p>
</section>

<section class="section">
  <header class="section-heading">
    <h2>When to use this group</h2>
  </header>
  <ul>
    <li>A new project starts and no one has written down what must be true for success.</li>
    <li>Stakeholders give conflicting descriptions of the same process.</li>
    <li>An incident keeps recurring and the fix requires understanding how work actually happens, not just how it is documented.</li>
    <li>A change request arrives without clear scope or verification criteria.</li>
    <li>A system replacement is planned and no one knows which business rules the current system enforces.</li>
    <li>A data quality issue spans multiple departments and ownership is unclear.</li>
    <li>You need to define what "done" means before implementation begins.</li>
  </ul>
</section>
