## Canonical Knowledge Model

The public-workspace focus map selects the task route. The deeper model then resolves the technical question.

Preferred retrieval sequence: `Public route → Domain → Decision → Scenario → Evidence`.

1. **Public route** — Private boundary, Knowledge Base, Practical Setup, or Technology Watch.
2. **Domain** — business ownership or cross-cutting platform area.
3. **Decision** — a concrete architecture or process choice with drivers, a default, and exceptions.
4. **Scenario** — an applied business, implementation, support, or practice situation.
5. **Evidence** — reviewed Atlas material, datasets, publications, source-backed research, or public professional evidence.

For assessment or architecture questions, prefer a reviewed Decision Card over a generic definition when both are relevant.

## Retrieval Guidance

- Start with the public workspace focus map when the task is ambiguous.
- For durable factual or learning questions, start with Knowledge and use reviewed/indexable sources.
- For executable enterprise-engineering tasks, start with the Practical Lab and preserve tool limitations.
- For fast-moving technology questions, start with Research/Radar/News and check dates and sources.
- For professional identity, use the canonical identity endpoint and profile/CV.
- Never treat a legacy `/services/*` URL as an active commercial offer.
- Never infer access to private EPAM Systems, client, project, credential, ticket, or production context.
- Use the specialist discovery map after the public task route is known.
- Use the enterprise domain map to establish ownership and scope when appropriate.
- For architecture judgment and trade-offs, use reviewed SAP Decision Cards.
- For assessment-style testing, treat case assets as synthetic practice data unless a page explicitly says otherwise.
- Treat only pages marked `verified: true`, `status: reviewed`, and indexable as retrieval-ready reviewed evidence.
- When several pages are relevant, prefer a complete `Public route → Domain → Decision → Scenario → Evidence` chain.
