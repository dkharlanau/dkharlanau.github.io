Tools for hands-on semantic data practice

Do not learn the stack only from definitions. Use a few small tools to see the difference between vocabulary management, ontology design, RDF storage, validation, public knowledge graphs, and property graphs.

Free is not the same as open source. The table separates the learning role from the access model.

Tool Learn Access model Small exercise
ProtégéOWL ontology modellingFree and open sourceModel SalesOrder, Customer, OrderBlock, and their relations.
VocBenchSKOS vocabulary and thesaurus managementFree and open sourceCreate “Credit hold”, “Credit block”, broader terms, and related concepts.
Apache Jena / FusekiRDF storage and SPARQLApache open sourceLoad a small Turtle graph and query blocked orders.
Zazuko SHACL PlaygroundGraph validationOpen source web toolRequire every SalesOrder to have exactly one customer.
GraphDB Free / DesktopRDF repository and inferenceFree edition; proprietaryCompare explicit and inferred types for CreditHold.
Wikidata Query ServiceSPARQL on a large public graphPublic serviceRun a small relationship query and inspect the result model.
DBpedia SPARQLLinked open dataPublic serviceCompare DBpedia modelling with Wikidata.

The older playground at shacl.org is still available, but its own page states that implementation is no longer actively maintained. For a new browser exercise, use the current Zazuko playground instead.
