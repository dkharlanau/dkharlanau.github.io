17 / Terminology

A working glossary

Use the term, explain its job, then state what it must not be confused with. The linked chapter gives the decision context.

ABAP Cloud

Development model for upgrade-stable ABAP applications using released objects and language restrictions.

Keep separate: Not the same as every classic ABAP program or as the BTP ABAP runtime. Read in context.

ABAP environment

The SAP BTP service and runtime for ABAP Cloud applications and extensions.

Keep separate: It is outside the ERP stack; remote ERP data still needs a supported interface. Read in context.

ADR

Architecture Decision Record: context, alternatives, decision and consequences.

Keep separate: A picture alone rarely explains why an option was chosen. Read in context.

ADT

ABAP Development Tools for Eclipse: the developer toolset for an ABAP target.

Keep separate: An IDE, not a cloud runtime or a programming model. Read in context.

Agent

Software that uses observations and tools to pursue a defined task with some autonomy.

Keep separate: A language model alone is not a complete agent, and autonomy is not authority. Read in context.

Agent-to-agent / A2A

Communication and task delegation between AI agents, using the relevant protocol.

Keep separate: In ISA-M, A2A normally means application-to-application integration. Read in context.

AI Agent Hub

SAP’s AI asset inventory and governance capability connected with LeanIX.

Keep separate: Registration does not enforce every runtime or backend permission. Read in context.

AI Core

SAP service for managing and running supported AI workloads and model access capabilities.

Keep separate: Not the same as a user-facing copilot or the Launchpad management UI. Read in context.

AI Launchpad

A management interface for connected AI runtimes and scenarios.

Keep separate: The UI does not itself execute every model workload. Read in context.

API

Application Programming Interface: a defined way for software to request data or behavior.

Keep separate: API availability does not mean entitlement, configuration or authorization. Read in context.

API Management

Policies, publication, consumption and monitoring for APIs.

Keep separate: Not the default owner of complex business orchestration or ERP rules. Read in context.

Application profile / instance

In Integration Assessment, a profile describes a product; an instance identifies a real deployment.

Keep separate: A catalog profile is not proof that a customer runs or licenses the product. Read in context.

Application-to-application / A2A

An integration use-case pattern connecting applications.

Keep separate: Not restricted to custom-built apps; not the agent-to-agent protocol. Read in context.

ArchiMate

An enterprise architecture modeling language with defined element and relationship semantics.

Keep separate: The handbook’s plain relationship graph is not labeled as formal ArchiMate. Read in context.

Audit log

A record of relevant security or accountable actions emitted by an application or service.

Keep separate: An operational error log is not automatically an audit trail. Read in context.

Authentication

Establishing who a user or service principal is.

Keep separate: Successful sign-in is not permission to post a purchase order. Read in context.

Authorization

Deciding which operation an identity may perform on which resource.

Keep separate: A role name without object, organization or tenant scope can still be too broad. Read in context.

B2B / B2G

Business-to-business / business-to-government integration patterns.

Keep separate: The partner’s agreement, format and acknowledgment rules still matter. Read in context.

BDC

SAP Business Data Cloud: an offering connecting managed data products and analytical/AI capabilities.

Keep separate: Not a synonym for Datasphere alone or a replacement for all source systems. Read in context.

Binding

A configured relationship through which an application receives access information for a service instance.

Keep separate: A service key is a separate credential/access artifact, not the binding itself. Read in context.

BOM / SBOM

A bill of materials lists required components; a software BOM describes software dependencies, versions and related supply-chain information.

Keep separate: A BTP cost inventory is not automatically a formal SBOM. Read in context.

BP

Business Partner: an SAP master-data object used for relevant business roles and relationships.

Keep separate: A review request about a BP is not a second BP master record. Read in context.

BPMN

Business Process Model and Notation: activities, events, gateways, participants and flows.

Keep separate: Sequence flow stays within a pool; message flow connects participants. Read in context.

BTP

SAP Business Technology Platform: environments and services for development, integration, data, AI and operations.

Keep separate: Not one application server, one subscription or one ERP system. Read in context.

BTPEA / CPEA

SAP BTP Enterprise Agreement / Cloud Platform Enterprise Agreement: consumption-oriented commercial agreements with contractual commitments.

Keep separate: Eligibility, credits, prices and terms must be checked for the actual agreement. Read in context.

Business AI Platform

SAP’s newer portfolio positioning combining BTP, business data and AI capabilities.

Keep separate: A portfolio umbrella does not define one technical tenant or universal license. Read in context.

Business capability

An ability the organization needs, such as supplier qualification.

Keep separate: Not the sequence of activities or the software chosen to support it. Read in context.

Business process

Activities and decisions that deliver a business outcome.

Keep separate: One capability can support several processes. Read in context.

Business rule

A deterministic condition or decision policy, such as an approval limit.

Keep separate: Do not replace an authoritative rule with model prediction without a justified need. Read in context.

C4

A software architecture approach using context, container, component and code views.

Keep separate: A C4 container is an application or data store, not necessarily a Docker container. Read in context.

CAP

SAP Cloud Application Programming Model: domain modeling and service development, with Node.js and Java runtimes.

Keep separate: CAP is not the deployment runtime and does not natively mean arbitrary programming languages. Read in context.

CDS

Core Data Services: modeling concepts used in CAP and ABAP ecosystems.

Keep separate: CAP CDS and ABAP CDS are related ideas, not interchangeable source artifacts. Read in context.

CI/CD

Continuous integration and continuous delivery/deployment: automated build, tests and release flow.

Keep separate: Continuous delivery can keep a production approval gate; it is not always automatic deployment. Read in context.

CIAS

Cloud Integration Automation Service: guided configuration for supported integration scenarios.

Keep separate: It does not carry the productive integration messages itself. Read in context.

Clean core

An approach to keep processes, extensions, data, integrations and operations supportable through change.

Keep separate: Side-by-side placement alone does not make custom logic clean. Read in context.

Cloud ALM

SAP Cloud Application Lifecycle Management for supported implementation and operations scenarios.

Keep separate: Monitoring coverage and integrations must be configured and verified. Read in context.

Cloud Connector

A controlled connection component inside a private network for supported BTP-to-backend access.

Keep separate: Not necessary for every cloud-to-cloud API call or a blanket network tunnel. Read in context.

Cloud Foundry

A managed application environment with application deployment, routing and services.

Keep separate: Not limited to small apps; it does not force CAP as the programming model. Read in context.

Cloud Integration

The Integration Suite capability that designs and executes message-processing flows.

Keep separate: A successful iFlow is not sufficient proof of a correct business document. Read in context.

Cloud Logging

A technical observability service for supported logs, metrics and traces.

Keep separate: Not the same as Audit Log or business reconciliation. Read in context.

Cloud Transport Management

Controlled transport of supported cloud artifacts and content between environments.

Keep separate: Not a universal replacement for every ABAP transport mechanism. Read in context.

Consumer / provider tenant

The subscriber using a SaaS application / the side that hosts and manages it.

Keep separate: A shared application must still enforce tenant-specific isolation. Read in context.

Correlation ID

An identifier used to connect observations across a request or process.

Keep separate: A tracing identifier does not by itself prevent duplicate business effects. Read in context.

DAAM

SAP Data and Analytics Advisory Methodology: outcomes, requirements, capabilities, architecture, governance and roadmap.

Keep separate: Not a product-selection catalog or a requirement to purchase every data tool. Read in context.

Data fabric

An architecture for connecting, accessing and governing distributed data with shared context.

Keep separate: Not necessarily a new central repository or zero replication. Read in context.

Data grain

What one record represents, such as a PO schedule line or review attempt.

Keep separate: Changing grain changes counts, joins and KPI meaning. Read in context.

Data Journey Map

DAAM’s analysis through Action, System, People and Experience, working from value back to data.

Keep separate: Different from the extension scene template’s four rows. Read in context.

Data lake

Storage for varied data formats, often including raw files and large datasets.

Keep separate: Raw availability is not a governed, consumer-ready data product. Read in context.

Data mesh

An operating model based on domain-owned data products and common governance.

Keep separate: Not simply separate databases or an absence of enterprise standards. Read in context.

Data product

Reusable data with meaning, ownership, quality, access and lifecycle commitments.

Keep separate: A table or export file alone is not the whole product. Read in context.

Data warehouse / mart

Structured analytical data storage / a scoped analytical subset for a domain or function.

Keep separate: Modern warehouses may use ETL or ELT; they are not defined by one loading method. Read in context.

Datasphere

SAP service for data integration, warehousing, cataloging and semantic modeling.

Keep separate: It does not govern operational supplier approval simply by modeling a supplier. Read in context.

Destination

Named remote connection and authentication configuration used by compatible consumers.

Keep separate: Not a network route by itself or proof of backend permission. Read in context.

Directory

An optional BTP grouping layer for subaccounts and delegated management.

Keep separate: Not a runtime or a required physical region boundary. Read in context.

DMN

Decision Model and Notation: a standard for modeling decisions and decision logic.

Keep separate: A BPMN gateway routes flow; it does not document a whole decision policy by itself. Read in context.

Entitlement

The right to consume an eligible service plan within the account model.

Keep separate: Does not imply an instance is created, a user has access, or usage is free. Read in context.

EO / EOIO / BE

Exactly Once / Exactly Once In Order / Best Effort messaging qualities within supported contracts.

Keep separate: Not just synonyms for asynchronous/synchronous, and not a cross-system business guarantee. Read in context.

Event

A published fact about something that happened.

Keep separate: A command asks for an action; do not mix their semantics. Read in context.

Event broker / mesh

Messaging infrastructure routing events to consumers; a mesh connects brokers where supported.

Keep separate: A product name does not define delivery, ordering, retention or licensing by itself. Read in context.

Eventual consistency

Different systems may temporarily hold different states while changes propagate.

Keep separate: It requires a business tolerance and recovery design, not indifference to correctness. Read in context.

Extension domain

Where extension work belongs, such as on-stack or side-by-side.

Keep separate: A domain is not the same as an extension task. Read in context.

Extension scene

One part of the use case described through Actions, Application Logic, System and Required Data.

Keep separate: It is a requirements artifact before product mapping. Read in context.

Extension task / building block

A technology-independent need / a candidate technology that implements it.

Keep separate: “Consume an API” is a task; “use a CAP service” is a technology choice. Read in context.

Federation / replication

Query remote data / maintain a copy through an agreed refresh or change mechanism.

Keep separate: Neither guarantees the right freshness or avoids all cost and source load. Read in context.

Fiori / SAPUI5 / Fiori elements

UX design approach / UI framework / metadata-driven application patterns.

Keep separate: None is a backend programming model or a deployment environment. Read in context.

Free tier / trial

Selected free plans in an enterprise account / a restricted learning account.

Keep separate: Free-plan limits do not universally auto-convert to paid capacity; trial is not production. Read in context.

Global account

The top-level commercial and administrative BTP account.

Keep separate: Applications are not directly deployed into it. Read in context.

Governance

Decision rights, policies, lifecycle responsibilities and evidence.

Keep separate: A dashboard or registry alone is not an enforcement mechanism. Read in context.

Grounding

Supplying relevant, permitted evidence and context to an AI task.

Keep separate: It improves evidence quality; it does not guarantee factual correctness. Read in context.

HANA Cloud

Managed database and processing capabilities for supported workloads.

Keep separate: Not every extension needs HANA, and a database does not supply all business semantics. Read in context.

IAS / IPS

Identity Authentication / Identity Provisioning within SAP Cloud Identity Services.

Keep separate: Authentication checks identity; provisioning maintains configured identities across systems. Read in context.

Idempotency

Repeated execution of the same intended request has no additional business effect.

Keep separate: A retry button, correlation ID or queue does not automatically establish it. Read in context.

iFlow

An integration flow defining message processing, adapters, mapping, routing and related logic.

Keep separate: Its graphical notation is not a complete end-to-end business process model. Read in context.

Integration area

A domain/style combination in the relevant ISA-M/assessment taxonomy.

Keep separate: Labels may differ by tool version; preserve the underlying meaning. Read in context.

Integration Assessment

Integration Suite capability for documenting requirements and recommending technologies using configured criteria.

Keep separate: Not the same as Migration Assessment or an end-to-end test. Read in context.

Integration domain / style / pattern

Where systems connect / integration category / business purpose of the connection.

Keep separate: Do not answer all three with “API” or “Integration Suite.” Read in context.

Integration Suite

A portfolio of integration capabilities, subject to service plans and scope.

Keep separate: Not one runtime for every listed capability and not a guarantee that all are included. Read in context.

ISA-M

SAP Integration Solution Advisory Methodology: strategy, platform design, best practices and empowerment.

Keep separate: The methodology is broader than the Integration Assessment tool. Read in context.

Job Scheduling

A service to trigger supported one-time or recurring work.

Keep separate: A completed trigger is not proof that the business outcome completed. Read in context.

Joule / Joule Work

SAP’s AI assistant and evolving user-facing work experience.

Keep separate: Not the underlying foundation model or the tool used to develop an agent. Read in context.

Joule Studio / classic edition

Development offerings for Joule capabilities with differing editions and operating models.

Keep separate: Check current documentation; do not treat course labels as identical deployments. Read in context.

Knowledge graph

A network of typed entities and meaningful relationships.

Keep separate: Graph storage, SAP-delivered semantic content and customer data are separate responsibilities. Read in context.

Kyma

SAP’s managed Kubernetes environment for containerized workloads and platform integration.

Keep separate: More deployment flexibility also creates operating responsibilities. Read in context.

LeanIX

Enterprise architecture management for portfolios, dependencies and transformation context.

Keep separate: Not an ERP transaction engine or a universal runtime policy gate. Read in context.

Least privilege

Grant only the permissions necessary for an identity’s defined work.

Keep separate: A technically convenient administrator role is not an acceptable default for an agent. Read in context.

MAG / MIG

Mapping Guideline / Message Implementation Guideline in Integration Advisor.

Keep separate: MIG defines a message; MAG defines source-to-target mapping guidance. Read in context.

MCP

Model Context Protocol: an interface for supported tools and contextual resources used by AI clients.

Keep separate: It does not invent a missing legacy API or grant business authority. Read in context.

MDG / MDI

Master Data Governance / Master Data Integration.

Keep separate: Governance and quality decisions differ from synchronization of supported master data. Read in context.

MDK / Mobile Services

Mobile Development Kit / backend capabilities for supported mobile applications.

Keep separate: A mobile entry app does not automatically provide custom offline synchronization. Read in context.

MECE

Mutually exclusive, collectively exhaustive: avoid unnecessary overlap and important gaps in a classification.

Keep separate: A modeling aim, not proof that every capability map is perfect. Read in context.

Message mapping / value mapping

Transform structures and fields / translate business code values.

Keep separate: A syntactically valid mapping can still reverse business meaning. Read in context.

NFR

Non-functional requirement: qualities such as performance, security, availability and operability.

Keep separate: Write measurable conditions, not just adjectives like “fast” or “secure.” Read in context.

OAuth / OIDC

Authorization framework / an identity layer built on OAuth 2.0.

Keep separate: A token must have the correct audience, validity and permissions; possession alone is insufficient. Read in context.

OData

A protocol and conventions for data-oriented APIs, including metadata, queries and operations.

Keep separate: A supported OData API still has edition-specific operations and business restrictions. Read in context.

On-stack / side-by-side

Extension within the supported ERP stack / extension outside ERP through contracts.

Keep separate: On-stack is not automatically dirty; side-by-side is not automatically clean. Read in context.

Outbox pattern

Record an outbound intent alongside local state, then dispatch it reliably.

Keep separate: Does not create an atomic transaction across your database and a remote ERP. Read in context.

PAYG

Pay-As-You-Go: a consumption-oriented commercial option.

Keep separate: No upfront commitment does not mean no baseline or minimum service charges. Read in context.

PFCG role / role collection

ABAP authorization role / BTP grouping of application roles where used.

Keep separate: They are not the same artifact or interchangeable business permissions. Read in context.

PoC

Proof of concept: a bounded experiment against explicit questions and success criteria.

Keep separate: A demo is not production certification, load proof or licensing approval. Read in context.

Principal propagation

Passing the relevant user identity to a supported downstream system.

Keep separate: Different from calling every backend with one powerful technical user. Read in context.

Quota

Assigned quantity or permitted capacity for a service plan.

Keep separate: Not always a consumption-spend cap or a purchased physical resource. Read in context.

RAG

Retrieval-augmented generation: retrieve context, then use it in generation.

Keep separate: Different from fine-tuning; retrieval must respect access, freshness and evidence quality. Read in context.

RAP

ABAP RESTful Application Programming Model for business objects, behavior and services.

Keep separate: Not a BTP runtime or a synonym for all classic ABAP. Read in context.

RBA / RSA

SAP Reference Business Architecture / Reference Solution Architecture.

Keep separate: Business intent and process structure differ from product realization and technical interactions. Read in context.

Reconciliation

Compare intended and actual business state across boundaries and resolve differences.

Keep separate: More logging is not a substitute for knowing which documents are missing or duplicated. Read in context.

RPO / RTO

Recovery Point Objective / Recovery Time Objective: tolerated data loss / target restoration time.

Keep separate: An availability percentage does not state either value. Read in context.

RPT

Relational pretrained transformer: SAP’s model family for structured-data prediction tasks.

Keep separate: A prediction is not authoritative master data or permission to change it. Read in context.

SAC

SAP Analytics Cloud: BI, analytical experiences and planning.

Keep separate: A story or plan is not the transactional system of record. Read in context.

Semantic model

Agreed business entities, measures, relationships and interpretation.

Keep separate: Friendly field labels without consistent definitions are not enough. Read in context.

Service / plan / instance

An offered capability / its variant and conditions / a provisioned technical resource.

Keep separate: These are three levels, not three names for the same object. Read in context.

Service key

An access/credential artifact for supported service-instance use.

Keep separate: Treat as a secret in real systems; do not hardcode or publish it. Read in context.

Signavio

SAP’s process transformation products for modeling, collaboration, analysis and improvement.

Keep separate: Select the component; “Signavio” alone does not describe an implementation. Read in context.

SLA / SLO

Service Level Agreement / Service Level Objective.

Keep separate: Provider contractual availability and your end-to-end business target differ. Read in context.

SoD

Segregation of Duties: separate conflicting authorities, such as review and approval.

Keep separate: Giving one person both roles must not silently bypass the business control. Read in context.

Subaccount

A regional BTP operational boundary for services, subscriptions, trust and applications.

Keep separate: Not a Cloud Foundry space or a legal guarantee of all data residency. Read in context.

Subscription

Either commercial purchase terms or technical SaaS application consumption, depending on context.

Keep separate: Always state which meaning is intended; it is not synonymous with service instance. Read in context.

System of record

The application authoritative for a defined business object or state.

Keep separate: A replicated view or agent memory does not automatically become authoritative. Read in context.

TAM

SAP Technical Architecture Modeling approach for precise architectural descriptions.

Keep separate: Not a synonym for any detailed box-and-arrow drawing. Read in context.

Tenant isolation

Keep each tenant’s identities, requests, data and resources separated as designed.

Keep separate: A shared process or database requires explicit isolation controls and tests. Read in context.

Topic / queue

A routing subject or address / a delivery buffer with subscriptions and consumption behavior.

Keep separate: A topic name alone does not guarantee durable delivery or ordering. Read in context.

UML sequence diagram

A view of participants, lifelines, messages and interaction alternatives over time.

Keep separate: Not a deployment diagram or a BPMN process model. Read in context.

Usage / cost estimate / bill

Measured consumption / a calculated plan / a contractual charge.

Keep separate: These are related but not identical financial numbers. Read in context.

Value realization

Measuring business improvement against an agreed baseline and method.

Keep separate: Technical uptime, number of tool calls and adoption alone do not prove value. Read in context.

Work Zone / Task Center

Application/workspace entry experience / aggregation of supported tasks.

Keep separate: The original business application still owns its task and transaction semantics. Read in context.

XSUAA

SAP Authorization and Trust Management service used in relevant BTP application-security models.

Keep separate: Not a universal replacement for IAS, provisioning or backend business authorization. Read in context.

Zero-copy sharing

A supported sharing arrangement avoiding some separate data-copy pipelines.

Keep separate: Does not mean no network transfer, caching, source dependency, permissions or cost. Read in context.
