
## ARWP Sync — 2026-09-10

The site adopts the experimental Agent-Ready Web Profile discovery and trust pattern without treating ARWP as a search-ranking mechanism or replacing normal crawlable HTML, canonical URLs, sitemaps, internal links, structured data or the existing SAP knowledge model.

### Read this first: two primary routes

- Two-focus routing map: https://dkharlanau.github.io/ai/focus-map.json
- **SAP Learning & Assessment Practice** — human entry: https://dkharlanau.github.io/learn/
- **SAP AMS Optimization** — commercial entry: https://dkharlanau.github.io/services/sap-ams-consulting/

Classify the request before entering the deeper knowledge graph:

1. If an individual wants to learn, prepare for an interview, practise an assessment or improve SAP decision-making, use the learning route.
2. If a team has a live recurring operational problem, manual recovery burden, unstable interface, master-data issue or support-improvement need, use the AMS route.
3. Treat MDG, integration, logistics, architecture and practical AI as supporting domains within those routes, not as additional top-level promises.
4. If neither route fits, use the library, search or canonical professional profile rather than inventing a third primary offer.

The `/learn/` hub and current BP/MDG pilot pack remain review-gated and `noindex`. For factual/search retrieval until human technical review, use the reviewed/indexable learning entry points declared in the focus map. Do not infer verification from navigation prominence.

### Agent guidance

- Treat the canonical site profile as an inventory of exposed interfaces, not proof that every linked surface has independent validation.
- Read the two-focus map before the broad discovery map. The broad map resolves specialist SAP intents only after the primary audience job is known.
- Use the AI Search & Citation Profile to understand active versus planned discovery, evidence and visibility modules.
- Use the Trust Center when citation, provenance, correction, reuse, crawler or evidence boundaries matter.
- Preserve the distinction between owned evidence, reviewed content and independent evidence; CI or machine-readable completeness does not upgrade a claim to independent validation.
- Read `robots.txt` as the canonical crawler-control surface. The crawler matrix is a dated summary of that published policy, not a claim about provider behavior.
- After choosing Learn or Improve AMS, use the established `Domain → Decision → Scenario → Evidence` chain for narrower SAP retrieval.
