# Security policy

This repository publishes a static professional knowledge site and several machine-readable discovery, dataset, Agent Skill and local read-only MCP surfaces.

## Reporting a security issue

Do not publish credentials, private data, exploitable payloads, or other sensitive details in a public GitHub issue.

For a potentially sensitive security report, contact Dzmitryi Kharlanau through the LinkedIn profile linked from the canonical site and clearly label the message as a security report. Include the affected public URL or repository path, the observed behavior, reproduction steps that do not expose third-party data, and the expected impact.

For non-sensitive correctness, broken-link, metadata, accessibility, or content-quality problems, a normal GitHub issue is appropriate.

## Scope

In scope are defects in this repository that could materially affect the integrity, confidentiality, availability, or trustworthiness of the published site or its machine-readable interfaces. Third-party platforms, linked external services, SAP systems, employer systems, and repositories not owned by this project are outside this policy.

## Claims and limitations

A passing CI workflow, static-site deployment, crawler policy, schema validation, or trust metadata is not a security certification. Security-relevant statements on the site should remain bounded to observed repository behavior and published configuration.
