# Canonical Tool Roadmap

The canonical public backlog for tool development is:

- Source page: `labs/tool-roadmap/index.md`
- Public route: `https://dkharlanau.github.io/labs/tool-roadmap/`

Use this roadmap as the source of truth for tool names, priorities, scores, delivery status, and intended repository placement.

Do not create a second competing tool-idea list. New ideas should be evaluated against the existing roadmap and then added, merged, reprioritized, parked, or rejected there.

Naming convention: prefer literal engineering terms such as `validate`, `compare`, `reconcile`, `lint`, `profile`, `trace`, and `analyze`. Avoid generic product filler such as Doctor, Guard, Copilot, Assistant, Explorer, Navigator, Studio, or AI-powered.
