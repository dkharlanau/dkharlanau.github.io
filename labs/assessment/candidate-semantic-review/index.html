Decision 01

Keep the MRP quantity diagnosis.

CAND-PP-WRONG-QUANTITY adds a real signal: reconstruct the net requirement before changing the planned order.

Why it is useful

The current Production cases cover production model choice, production structure, staging, and cross-process completion. They do not isolate why MRP created too much, too little, or repeated supply.

Lead path

Requirement → stock and receipts → planning strategy → lot sizing → planning parameters → procurement type → net requirement.

Review gate

Do not accept a version that becomes a generic list of MRP settings. The answer must reconstruct the quantity decision.

Decision 02

Keep the goods-receipt boundary diagnosis.

CAND-PP-GR tests the difference between production progress and the actual finished-product inventory event.

Why it is useful

A confirmation can be correct while the expected finished product is still missing from the intended stock or warehouse context.

Lead path

Order quantity → GR relevance → quantity/UoM → storage, batch and quality context → automatic/manual GR → EWM inbound where used.

Review gate

Keep ownership explicit: Production progress, Inventory state, EWM execution and Quality status are related but not interchangeable.

Decision 03

Reject the production-cost candidate as a semantic duplicate.

CAND-PP-COST looks new to the lexical filter, but its reasoning is already covered by ASSESS-FIN-005.

Same business problem

A physically or technically complete production order still carries an unexplained financial balance.

Same reasoning

Actual debits → goods-receipt credits → order status → settlement rule/receiver → variance/WIP timing → settlement proof.

Better next case

If another finance case is needed, change the problem materially, for example sales-order settlement ownership or a period-end WIP design decision.

Working rule

Use two duplicate filters.

Lexical dedup protects the generator. Semantic review protects the assessment.
