Scoring model

Simple enough to challenge.

The model is deliberately transparent. If assessment needs change, weights can be changed in one generator instead of hiding judgement in a spreadsheet nobody remembers owning.

Direct practice reuse

4 points per published case that links directly to the page.

Cross-track reuse

3 points per distinct case track and 2 points per catalog track that uses the route as an entry point.

Evidence depth

1 point per source-supported reviewed claim, capped at four. Evidence is a prerequisite, not a substitute for assessment value.

policy

Boundary: every page on this list remains subject to the same seven human review gates. Ranking never changes verified, indexing, status, or factual-review state.
