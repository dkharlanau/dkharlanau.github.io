Lead signals

The source check changes how the answer is framed.

The useful result is not a citation count. It is a clearer boundary between documented behavior and consultant judgement.

Documented

  • Guaranteed delivery can redeliver.
  • Handled Cloud Integration exceptions can appear as Completed.
  • Copying control shapes billing data flow and pricing behavior.
  • Split analysis explains different billing header values.

Lead judgement

  • Do not equate a green technical status with business completion.
  • Do not replay before commit state and duplicate protection are understood.
  • Do not force one invoice when standard split criteria say otherwise.
  • Use the first wrong layer to assign ownership.

Still human-reviewed

  • Whether the explanation is complete for the intended audience.
  • Whether product and release scope are represented correctly across the whole page.
  • Whether a heuristic is too broad for a specific customer design.
  • Whether the page should remain draft/noindex.

Machine-readable evidence

Claims are explicit records.

Each reviewed claim carries source references, release scope, review date, and the human-verification boundary.
