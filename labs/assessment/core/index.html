How to practice

Rotate the same route through five levels.

Knowing a process is the first pass. The assessment signal comes from how far the explanation survives follow-up questions.

Explain → Trace

  • Explain the business purpose and owner.
  • Trace input → decision → output → consumer.
  • Name the evidence at each boundary.

Diagnose

  • Start from a symptom.
  • Build a small hypothesis tree.
  • Find the first wrong state and prove the cause.

Design → Challenge

  • Choose ownership and integration boundaries.
  • Explain trade-offs and failure recovery.
  • Challenge the design with volume, deployment, legal, or data constraints.
