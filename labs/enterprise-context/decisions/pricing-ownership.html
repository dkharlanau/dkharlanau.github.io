Decision Card / Sales Pricing

Where should SAP Sales
pricing logic live?

A wrong price is not a request for a pricing exit. First separate commercial data, search strategy, calculation sequence, eligibility, and true custom calculation.

My default

DATACondition recordCommercial value and validity
PATHCondition techniqueHow SAP finds the value
CODEExtension lastOnly for a real gap
Do not hide commercial policy inside code.
rule

Decision in one sentence: keep reusable prices and discounts in condition records, keep search and calculation structure in the standard condition technique, and use custom logic only when the requirement cannot be represented clearly by standard pricing objects.

Ownership map

Put each pricing decision in the narrowest standard layer.

DecisionPreferred owner
Commercial value and validityCondition record with explicit key, currency, unit, dates, and business owner.
Calculation sequencePricing procedure + condition types.
Which record winsAccess sequence + condition tables.
Condition eligibilityStandard requirements, exclusion, or condition controls when they match the rule.
True calculated gapBounded formula or released extension point with named inputs, tests, fallback, and owner.

Diagnosis

Find the first pricing decision that diverged.

Procedure

Confirm the expected pricing procedure and its determination inputs before analysing one condition line.

Condition

Check whether the expected price, discount, surcharge, freight, or tax component is present and active.

Search

Trace the access sequence and condition tables actually searched. A valid record in the wrong key is still not the selected record.

Record

Check key fields, dates, currency, unit, scales, and maintenance ownership.

Calculation

Only then inspect formulas, custom logic, external pricing, or repricing behavior.

warning

I change the default when: an external service is explicitly authoritative for pricing or the commercial calculation cannot be represented safely in the local condition model.

Anti-pattern: overwrite the final amount in code for selected customers or materials. The result can be technically correct and commercially impossible to explain.

Lead check: prove the pricing path and name the business owner of the value before approving custom logic.
