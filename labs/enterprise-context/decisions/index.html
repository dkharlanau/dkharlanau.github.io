Reusable answer frame

Context → drivers → default → exception → recovery.

  1. 01Context

    State the business outcome.

  2. 02Drivers

    Name what changes the decision.

  3. 03Default

    Give a preferred design.

  4. 04Exception

    Explain when the default fails.

  5. 05Recovery

    Name ownership and proof of completion.
