Problem: teams often call every large data movement a migration. Then an initial-load tool becomes a nightly interface, or a spreadsheet becomes an application architecture.

Working rule. Classify the need first: initial migration, source preparation, data quality, recurring integration, mass maintenance, governed processing, or controlled user upload.

Release boundary. The current source set covers SAP S/4HANA 2025 FPS01 and SAP S/4HANA Cloud Public Edition 2608. Available migration objects and supported migration methods depend on the target release, activated scope, source scenario, and selected migration approach.
