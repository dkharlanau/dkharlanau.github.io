Sales mechanism library / derivation layer

How did this value
get into the order?

A field can come from master data, a predecessor, a procedure, a runtime determination, or a manual change. The useful question is not only where the field is configured. The useful question is who owns the current value, when SAP recalculates it, and what consumes it next.

Lead answer pattern

When a field is wrong, answer in six moves.

  1. 01

    Name the field and document level.

  2. 02

    Separate copy, master data, procedure, runtime derivation, and manual override.

  3. 03

    Prove the winning source or access.

  4. 04

    Identify the event that should keep or recalculate the value.

  5. 05

    Trace downstream mechanisms that consumed the result.

  6. 06

    Change the narrowest owner and test one controlled variation.
