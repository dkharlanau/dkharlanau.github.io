Impact thinking

Four traces worth memorizing.

Plant changed

PLANT → SHIPPT → ROUTE → SCHED → ATP. Then ask whether company-code/intercompany context changed too.

Invoice price wrong

COPY → pricing type → PRICE → pricing procedure → access sequence → condition record.

Customer gets nothing

BILL / sales object exists → OUTPUT → output item → rule result → recipient → channel → dispatch/rendering status.

Wrong batch

BATCH → search procedure → strategy type → strategy key → selection class → availability → sort rule. Manual correction comes last, not first.

Process composition

The same mechanisms reappear across different business branches.

This is the reason for separating them. Third-party sales still needs pricing, partner, billing, copy and output. Make-to-order still needs item/schedule-line logic, scheduling, ATP and often batch context. The process changes; the mechanisms remain reusable.
