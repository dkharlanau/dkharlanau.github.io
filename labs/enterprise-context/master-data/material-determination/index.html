Material Determination Record

Material determination lets Sales replace a requested product with another product according to maintained substitution rules. Typical uses include successor products, customer-specific replacements or controlled substitutions during product transitions.

02condition recordData class
Condition type/key, requested material, validity and substitution reason.

Mental model

Know what the object owns before tracing a document.

database

Scope: Condition type/key, requested material, validity and substitution reason.

Important data

Requested material, substitute material, condition key, validity dates, substitution reason and context fields configured in the condition table.

Configuration boundary

The record says which substitution is valid. The determination procedure, condition type, access sequence and substitution-reason behavior are configuration.

Runtime use

How the data enters Order-to-Cash.

When the user enters a material, the determination procedure can find a valid substitution record and propose or apply the alternative. The resulting sales document item structure depends on the configured substitution reason and process design.

Troubleshooting

Start with the most specific evidence.

troubleshoot

Check the originally requested material, document date and sales context. Use the determination analysis where available to identify the condition access. Then verify the record and substitution reason before looking at ATP or item-category effects.

Assessment recall

A concise answer that still shows depth.

record_voice_over

Material determination is condition-technique-based substitution. The record maps a requested product to an alternative for a defined key and validity; configuration controls how that substitution behaves in the order.
