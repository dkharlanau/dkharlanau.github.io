Material Listing / Exclusion

Listing and exclusion control whether a customer is allowed to order a product. A listing is restrictive in a positive way: only listed products are allowed for the relevant context. An exclusion blocks specific products. Both act before downstream fulfillment can proceed normally.

Configuration boundary

The condition record contains the allowed or blocked relationship. The procedure and access sequence that search those records are configuration.

Runtime use

How the data enters Order-to-Cash.

During order entry SAP checks the configured listing/exclusion procedure. A matching exclusion can reject the item; a listing scenario can reject a product that is not present in the allowed set.

Troubleshooting

Start with the most specific evidence.

troubleshoot

First establish whether the process is using listing, exclusion or both. Check the customer/product key and validity. Then verify the assigned procedure and the access sequence if the expected record is not being read.

Assessment recall

A concise answer that still shows depth.

record_voice_over

Listing and exclusion are customer-product eligibility controls. I check the active procedure, exact condition key and validity before treating an order rejection as a product-master issue.
