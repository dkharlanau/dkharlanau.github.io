SAP Sales / Master Data / MD.SD.CROSS

Cross-Selling Assignment Data

Cross-selling recommends additional products when a main product is entered. It supports assisted selling and upsell scenarios, but it should be kept conceptually separate from substitution: the original product remains, while other products are suggested.

database

Scope: Main product, suggested products and configured sales context/profile.

Important data

Main product, suggested product list, sales context or condition key, cross-selling profile where used and proposal sequence.

Configuration boundary

Cross-selling proposes additional products. Material determination replaces a requested product; item proposal presents a reusable predefined basket. These are distinct mechanisms.

Runtime use

How the data enters Order-to-Cash.

During sales order entry the system can display related products for the user to add. The suggestion is normally optional; selected products become ordinary sales items and are then processed by normal pricing, ATP and delivery logic.

Troubleshooting

Start with the most specific evidence.

troubleshoot

Check whether the main product and sales context match the maintained cross-selling data. Then verify the assigned cross-selling profile or determination logic if suggestions do not appear.

Assessment recall

A concise answer that still shows depth.

record_voice_over

Cross-selling is recommendation data around a main product. It adds optional suggestions; it does not substitute the original item or automatically represent a free-goods entitlement.
