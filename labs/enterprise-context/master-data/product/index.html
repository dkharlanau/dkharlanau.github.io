SAP Sales / Master Data / MD.SD.PRODUCT

Product / Material

The product master is where commercial and logistics behavior meet. A material number alone says very little. Sales reads sales-area data, plant data, units, status and classification-related attributes. These values feed several determinations, so one incorrect field can surface as an order, ATP, shipping, pricing or billing problem.

Object profile

01MD.SD.PRODUCTCatalogue ID
02business masterData class
Product, sales organization, distribution channel, plant and unit-of-measure views.

Mental model

Know what the object owns before tracing a document.

database

Scope: Product, sales organization, distribution channel, plant and unit-of-measure views.

Important data

Item category group, delivering plant, sales unit, product hierarchy, product pricing group, account assignment product group, sales status, loading group, availability-checking group, transportation data, tax classification and alternative units of measure.

Configuration boundary

The product master supplies attributes. Configuration interprets them. For example, item category group is master data, while the item category determination table is configuration.

Runtime use

How the data enters Order-to-Cash.

Product data participates in item category determination, plant proposal, shipping-point determination, pricing keys, ATP, route and scheduling context, revenue account determination and text selection. Plant-level values become particularly important once the process moves from commercial order entry into fulfillment.

Troubleshooting

Start with the most specific evidence.

troubleshoot

Start with the material and exact sales area/plant used by the item. Compare the document value with the relevant product view, then trace the determination that consumes the field. Avoid checking a generic material screen without confirming organizational level.

Assessment recall

A concise answer that still shows depth.

record_voice_over

For a product issue I name the exact material view and field, not just 'material master'. Sales-area fields drive commercial behavior; plant fields drive ATP and shipping; configuration then interprets those values.
