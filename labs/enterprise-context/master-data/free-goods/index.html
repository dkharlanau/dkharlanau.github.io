SAP Sales / Master Data / MD.SD.FREEGOODS

Free Goods Condition Record

Free goods define quantity-based commercial incentives such as 'buy ten, receive one free'. The record describes when the incentive applies and how the free quantity is calculated.

Follow the runtime path arrow_downward

Object profile

01MD.SD.FREEGOODSCatalogue ID
02condition recordData class
Customer/product key, validity, minimum quantity and calculation rule.

Mental model

Know what the object owns before tracing a document.

database

Scope: Customer/product key, validity, minimum quantity and calculation rule.

Important data

Condition key, validity period, minimum quantity, free-goods quantity or ratio, unit and inclusive/exclusive calculation mode.

Configuration boundary

The condition record stores the commercial entitlement. Procedure assignment and item behavior are configuration.

Runtime use

How the data enters Order-to-Cash.

When the order quantity meets the maintained rule, free-goods determination can create or calculate a free-goods item/subitem. The exact item structure and pricing behavior depend on the configured process.

Troubleshooting

Start with the most specific evidence.

troubleshoot

Check the ordered quantity and unit, validity date and customer/product key. Then verify inclusive versus exclusive mode and the calculation rule before investigating item-category or pricing results.

Assessment recall

A concise answer that still shows depth.

record_voice_over

Free Goods is validity-based condition master data. I verify the threshold, quantity rule, unit and validity, then distinguish the entitlement record from the configuration that creates the free item.
