SAP Procurement / Source Allocation

Quota Arrangement: how demand is distributed across sources.

When several sources are available, the business may not want one supplier to receive all demand. Quota Arrangement provides time-dependent rules for allocating material requirements across sources.

Start with the mental model arrow_downward
rule

Boundary: SAP documentation can describe Quota Arrangement as a purchasing document and as sourcing administration data. In this catalogue it stays in the adjacent sourcing layer. It is not the same kind of business master as Customer, Supplier, or Material.

Mental model

Eligibility and allocation are different decisions.

Source List helps answer whether a source may be used. Quota Arrangement helps answer how requirements should be allocated among sources over time.

Material + plant

Defines the requirement population.

Validity

Defines the period in which the quota applies.

Quota item

Represents one source in the arrangement.

Quota and allocated quantity

Drive the source allocation and rating logic over time.

Quota rating

The next source is chosen from current allocation state, not from the quota percentage alone.

Outside MRP splitting, SAP calculates a quota rating for every usable quota item and assigns the source with the lowest result.

functions

Formula: Quota rating = (Quota-allocated quantity + Quota base quantity) / Quota.

SupplierQuotaAllocated qtyBase qtyQuota rating
A37800260
B23800190
C10260260

Supplier B receives the next complete manual PR item because it has the lowest quota rating. After a 100-piece PR is saved, B's allocated quantity becomes 480 and its rating becomes 240.

balance

Equal ratings: when several sources have the same quota rating, SAP assigns the first quota item. It does not choose the source with the highest quota.

Key and scope

Know the key before you debug the value.

The same value can be correct in one sourcing context and wrong in another.

Runtime use

Quota is dynamic because history matters.

The next source can depend not only on the configured quota but also on quantities already allocated. A simple 60/40 explanation is incomplete without current allocation state.

Requirement

Start with material, plant, date, quantity, and procurement process.

02

Validity

Find the active Quota Arrangement and items.

03

Eligibility

Confirm that the referenced sources are usable in the sourcing context.

04

Rating

Check quota, allocated quantity, base quantity, maximum quantity, and source type.

05

Assignment

Verify which source received the requirement and how the allocated quantity changed.

Quota base quantity lets you correct the starting position.

If a new supplier joins an arrangement after the other suppliers have already received large quantities, a zero base quantity would make the new supplier appear artificially under-used. Set or calculate a quota base quantity so the new source starts from a realistic rating.

In MEQ1, SAP provides individual and collective base-quantity calculations. Collective calculation is useful when the goal is to bring the current quota ratings to the same level before new requirements are assigned.

Source determination role

Quota Arrangement is checked first, but manual PRs and MRP can use it differently.

A valid Quota Arrangement has the highest source-determination priority. The key question is whether SAP should assign one complete requirement to one source or split the requirement during planning.

RuntimeHow the requirement is assignedWhat drives the decision
Manual PR / outside MRPThe complete PR item is assigned to one source.Lowest quota rating; if ratings are equal, the first quota item.
MRP without splittingThe procurement proposal is assigned to one source.Quota rating plus the normal quota-item limits and eligibility rules.
MRP with splittingOne requirement can be divided into several procurement proposals according to the quotas.The splitting lot-sizing procedure and the quota proportions. During splitting, quota rating and current allocated quantity are not used to calculate the split.

Standard training uses lot-sizing procedure ES — lot-for-lot with splitting as the example. A minimum split quantity in the quota header prevents small requirements from being split. If the requirement is below that threshold, SAP assigns it to one source using the normal quota logic.

school

Assessment memory: a 70/30 quota does not mean every manual PR is split 70/30. Manual source determination gives the whole PR item to one source. A single requirement is divided only when MRP splitting is configured.

Planning controls

Quota items can limit lot size, total allocation, and source priority.

These fields are useful when a percentage alone is not enough to model capacity or commercial limits.

ControlMeaningRuntime effect
Minimum lot sizeSmallest proposal quantity for the source.Used in MRP. If the calculated quantity is smaller, SAP can raise it to the source minimum.
Maximum lot sizeLargest quantity per procurement proposal for the source.Used in MRP. A larger requirement can create several proposals for the same source.
1xAllows the source to receive the configured maximum lot only once for the requirement.The remaining quantity is routed to other sources instead of creating repeated maximum-size proposals for the same source.
Maximum quantityUpper limit for the quota-allocated quantity.Used both outside MRP and in MRP. A source is no longer proposed when the new assignment would meet or exceed the configured limit.
Priority / maximum release quantityLets a preferred source be consumed up to a controlled capacity before another source is used.Useful, for example, when internal production should cover demand up to a monthly capacity and an external supplier should cover the excess.
contract

Contract control: if an outline agreement is MRP-relevant through the Source List, its target quantity can be copied conceptually into the quota item's maximum quantity. This adds an exhaustion check that the Source List alone does not perform.

Lead diagnosis

Find the owning layer before changing data.

If a quota looks correct but assignment is wrong, the missing evidence is often validity, quota usage, source eligibility, or current allocated quantity.

Start here

Check material + plant → validity → quota items → source eligibility → allocated/base quantities → quota rating → assigned source.

Do not jump here

Do not explain quota as a static percentage split of every purchase requisition line. The sourcing logic works across requirements and current allocation state.

record_voice_over

Assessment answer: “Quota Arrangement distributes requirements among sources for a material and plant. Outside MRP, SAP calculates (allocated quantity + base quantity) / quota and assigns the source with the lowest quota rating. A manual PR item is assigned completely to one source. MRP can split one requirement only when a splitting lot-size procedure such as ES is active. Then I check min/max lot size, 1x, maximum quantity, and source eligibility before changing the quota.”
