SAP Procurement / Relationship Data

Purchasing Info Record: how this supplier supplies this material.

A supplier can supply many materials, and one material can have many suppliers. The Purchasing Info Record is the reusable relationship layer between them, with purchasing-specific commercial and delivery data.

Start with the mental model arrow_downward
rule

Boundary: PIR is not the supplier master and not the material master. It specializes the supplier × material relationship. Source List, Quota Arrangement, and outline agreements can still decide which source is selected.

Mental model

Think supplier × material × purchasing context.

If purchasing behavior is wrong for only one supplier-material pair, the info record is one of the first objects to inspect.

Runtime use

PIR supplies reusable defaults; source determination decides whether it is used.

The info record can support MRP, requisition and PO processing, but another source-of-supply object can be more decisive for source selection.

Lead diagnosis

Find the owning layer before changing data.

When only one supplier-material combination is wrong, compare the PIR with supplier, material, source list, agreement, and final PO values.

Start here

Check supplier + material + purchasing organization + plant + info record category + validity/conditions.

Do not jump here

Do not change the generic material master to fix a supplier-specific lead time or order unit unless the generic value is truly the owner.
