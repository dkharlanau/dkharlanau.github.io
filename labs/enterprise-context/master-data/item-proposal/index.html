Sales Item Proposal

An item proposal is a reusable shopping list for sales order entry. It is useful when a customer repeatedly orders the same set of products. Instead of entering each line manually, the user can call a proposal and copy selected items and quantities into the document.

Important data

Proposal identifier, products/materials, proposed quantities, units, sales area and customer assignment or usage context.

Configuration boundary

Item proposal data is not cross-selling and not a material determination rule. It is an explicit reusable list, whereas cross-selling recommends additional products and material determination substitutes a requested product.

Runtime use

How the data enters Order-to-Cash.

The proposal supports faster order and quotation entry. It does not create a sales order by itself; it supplies reusable item suggestions that become normal document items after selection.

Troubleshooting

Start with the most specific evidence.

troubleshoot

If expected proposal items are missing, confirm the proposal assignment and sales area, then inspect the products and quantities stored in the proposal. After copying, troubleshoot the resulting item as a normal sales document item.

Assessment recall

A concise answer that still shows depth.

record_voice_over

Item Proposal is reusable entry assistance: a predefined set of products and quantities that can be copied into a sales document. It is different from substitution or recommendation logic.
