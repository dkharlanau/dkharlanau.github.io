SAP Sales / Master Data / MD.SD.ADDRESS

Business Partner Address / Address Usage

A Business Partner can have several physical addresses. The important question is therefore not only which BP is used, but which address is valid for a specific role, date and business context. Address usage gives SAP a controlled way to select the correct address instead of treating every address as interchangeable.

database

Scope: Business Partner, address UUID, address usage, validity and partner/document context.

Important data

Address UUID, address usage, validity dates, postal data, communication data and address-dependent customer information where supported.

Configuration boundary

Address determination is not the same as partner determination. Partner determination selects the business partner for a role; address logic selects which physical address of that partner is relevant.

Runtime use

How the data enters Order-to-Cash.

During sales processing the selected address can become the ship-to, bill-to or other partner address copied into the document. It can affect delivery execution, tax-relevant location context, outputs and integrations that transmit partner addresses downstream.

Troubleshooting

Start with the most specific evidence.

troubleshoot

Compare the address stored in the document with the BP address records and their validity. Check address usage and partner role first. Then investigate document-specific address changes or interface payloads.

Assessment recall

A concise answer that still shows depth.

record_voice_over

I treat address data as a separate relationship layer below the Business Partner. First determine the partner, then determine the valid address usage and confirm what was copied into the document.
