Pricing Condition Record

A pricing condition record is the maintained commercial value that pricing searches for. Price, discount, surcharge, freight or another condition can be stored against a specific key combination such as customer/material or price list/product hierarchy.

Mental model

Know what the object owns before tracing a document.

database

Scope: Condition type, condition table/key combination, validity, currency/unit and scales.

Important data

Condition type, key fields, amount or percentage, currency, pricing unit, valid-from/to dates, scales and condition-specific control data.

Configuration boundary

Condition type, access sequence and pricing procedure are configuration. The condition record is master data. This distinction is central when troubleshooting pricing.

Runtime use

How the data enters Order-to-Cash.

The pricing procedure calls condition types. Their access sequences search condition tables in order. When a valid record is found, the record supplies the value that appears as a pricing condition in the sales document.

Troubleshooting

Start with the most specific evidence.

troubleshoot

Start from the condition line in pricing analysis. Identify the condition type and access attempted, then check the exact key combination and validity of the record. Also verify currency, unit and scale basis.

Assessment recall

A concise answer that still shows depth.

record_voice_over

Pricing configuration defines how SAP searches; the condition record contains the commercial value. I use pricing analysis to see which access was attempted and why a record was or was not found.
