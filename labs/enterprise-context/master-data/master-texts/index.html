SAP Sales / Master Data / MD.SD.TEXT

Master Text Sources

Texts in sales documents are often copied from reusable sources rather than typed manually. Customer, product and other master records can hold language-dependent texts that are selected and copied according to text-determination rules.

Mental model

Know what the object owns before tracing a document.

database

Scope: Text object, text ID, language, master object and sales-area context where relevant.

Important data

Text object, text ID, language, source master key, sales-area context and text content.

Configuration boundary

The text itself is maintained data. The text determination procedure, access sequence and copy behavior are configuration.

Runtime use

How the data enters Order-to-Cash.

At order creation, delivery or billing, text determination can search configured sources and copy the relevant text into the document. Later copy control and text procedures determine whether that text is inherited by follow-on documents or output.

Troubleshooting

Start with the most specific evidence.

troubleshoot

Identify the missing or wrong document text ID. Check the document language and source master text first, then trace the text determination access and any copy rules to follow-on documents.

Assessment recall

A concise answer that still shows depth.

record_voice_over

For texts I separate content from determination. The master record stores the reusable text; text determination decides which source is read and whether the text is copied into the document.
