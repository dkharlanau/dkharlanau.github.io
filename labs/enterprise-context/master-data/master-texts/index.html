SAP Sales / Master Data / MD.SD.TEXT

Master Text Sources

Texts in sales documents are often copied from reusable sources rather than typed manually. Customer, product and other master records can hold language-dependent texts that are selected and copied according to text-determination rules.

Follow the runtime path arrow_downward

Object profile

01MD.SD.TEXTCatalogue ID
02content masterData class
Text object, text ID, language, master object and sales-area context where relevant.

Mental model

The master stores content; text determination decides where the document gets it.

database

Scope: Text object, text ID, language, master object and sales-area context where relevant.

Important data

Text object, text ID, language, source master key, sales-area context and text content.

Configuration boundary

The text itself is maintained data. The text determination procedure, access sequence and copy behavior are configuration.

Runtime use

A reusable text becomes a document snapshot through a search and copy decision.

At Sales, delivery, or billing creation, text determination can search configured sources for a specific text ID and language. When a source is found, its content can be copied into the business document. From that point, follow-on text behavior depends on later text and copy rules rather than on the source master alone.

01

Name the missing text

Start with the exact text ID, document level, language, and document where the content is wrong or missing.

02

Read the source content

Check the relevant customer, product, or other master source and prove that the required language and text actually exist.

03

Follow text determination

Trace the active text procedure and source sequence to see whether SAP reaches the expected master text.

04

Compare the document copy

Verify the text stored in the document. Once copied, the document can have its own text state and later changes to master content may not explain it.

05

Trace follow-on inheritance

If the source document is correct but delivery, billing, or output is wrong, move to copy and downstream text rules.

Troubleshooting

Separate source content, source selection, and document inheritance.

troubleshoot

Identify the exact text ID and language first. If the source master text is wrong, fix content. If the source is correct but the document text is missing, trace text determination. If the Sales document is correct but a follow-on document or output is wrong, inspect copy and downstream text rules. These are three different ownership layers.

Assessment recall

Content → source selection → document copy → inheritance.

record_voice_over

60-second answer: For Sales texts I separate content from determination. Master data stores reusable text by object, text ID, language, and context. Text determination decides which source is read and copied into the document. After the copy, follow-on documents and output can use their own text and copy rules. So I diagnose a missing text in order: source content, source selection, document snapshot, then inheritance.
