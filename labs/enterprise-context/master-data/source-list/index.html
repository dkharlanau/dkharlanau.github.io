SAP Procurement / Source of Supply

Source List: which sources may be used?

Supplier and Purchasing Info Record data can exist and still be unusable for a requirement. Source List adds time-dependent source eligibility for a material and plant and can mark sources as fixed or blocked.

Start with the mental model arrow_downward
rule

Boundary: Source List answers source eligibility. It does not replace supplier master data, the Purchasing Info Record, or the procurement document that will finally be created.

Mental model

Separate source existence from source eligibility.

The strongest diagnostic question is: “Which source-list record is valid for this material, plant, and requirement date, and what does that record say?”

Material + plant

Defines the demand context.

Validity

Limits the source record to a date range.

Source

Supplier, supplying plant, or supported agreement context.

Control

Fixed, blocked, and MRP/source-assignment indicators shape automatic selection.

Runtime context

Source List behavior depends on where source determination is running.

The same material can behave differently in MRP and in a manually processed purchase requisition because SAP uses different reference dates and different preference rules.

admin_panel_settings

User control: the EFB purchasing function-authorization parameter can prevent selected users from manually assigning a source of supply.

Key and scope

Know the key before you debug the value.

The same value can be correct in one sourcing context and wrong in another.

Field or dimensionWhy it mattersTypical process effect
Material / plantCore Source List context.Different plants can have different valid sources for the same material.
Validity start / endTime boundary for the record.Manual source determination checks the PR delivery date. MRP checks the requirements date; for reorder-point planning this is the current date.
Supplier + purchasing organizationIdentifies an external source and its purchasing context.The record can also reference a contract or scheduling-agreement item.
Procurement plantIdentifies an internal supplying plant instead of a supplier.SAP determines a plant as source only for PR item category U (Stock transfer). MRP-created PRs also need the matching special procurement setting.
Fixed sourcePreference control outside the planning run.Only one source of the same type can be fixed for the same validity period. If both an outline-agreement item and a PIR are fixed, the outline agreement wins.
Blocked sourcePrevents the source from being used.A blocked entry is excluded from source determination and cannot be assigned manually.
MRP indicatorControls explicit Source List use in planning.Indicator 1 makes the record MRP-relevant; indicator 2 additionally supports automatic scheduling-agreement schedule lines.

MRP control

MRP relevance and Fixed source are different controls.

This distinction is easy to mix up. The MRP indicator tells planning how to use the source-list record. The Fixed indicator is a separate sourcing control.

MRP indicatorMeaningAssessment point
BlankThe entry is not selected through the MRP source-list search based on MRP indicator 1 or 2.A source can still exist for purchasing without being the MRP-relevant source-list entry.
1Record relevant to MRP.MRP can use this valid source-list entry for source determination.
2Record relevant to MRP; schedule lines generated automatically.This is connected to scheduling-agreement planning. It does not mean “fixed” or “exclusive supplier”.
priority_high

Fixed is separate: outside MRP, when several valid Source List entries exist, a Fixed source can resolve the choice. If both an outline-agreement item and an info record are fixed, the outline-agreement item has priority.

MRP relevance can override the default sourcing path: when explicit MRP-relevant Source List entries exist, planning uses them before it falls back to scheduling agreements, contracts, or automatically sourced PIRs. Multiple MRP-relevant entries are useful with a Quota Arrangement.

Blocking

Block the source you mean to stop.

A Source List block is more precise than a general supplier block, but its effect depends on what is stored in the Source List entry.

Block patternEffectLead interpretation
Entry with outline-agreement itemThe blocked agreement item cannot be selected, assigned, released, or scheduled through that source.The material can still be purchased from the supplier without reference to that agreement if another valid path exists.
Entry without outline-agreement itemThe material/supplier or material/plant combination is blocked more broadly.Info records, outline agreements, and quota items for the blocked combination are no longer valid sourcing candidates.
Validity period with no supplierExternal procurement for the material is blocked in that plant for the period.This is a material-level sourcing stop, not only a supplier stop.
warning

Separate control: supplier purchasing or central blocks are maintained on the Business Partner. Open documents can still have follow-on behavior depending on the block type and process state, so do not treat a Source List block and a supplier master block as interchangeable.

Mandatory Source List and maintenance

A Source List can be optional master data or an enforced procurement control.

A plant-level Source List requirement means materials in that plant need a valid Source List entry before normal purchasing can use them.

Automatic generation can create Source List records from Purchasing Info Records, outline-agreement items, or both. Before generation, define the materials and plants, validity period, source types, treatment of existing records, and the indicators to set.

inventory_2

Exhausted agreement trap: the Source List does not check whether a contract or other outline agreement has already reached its target quantity. If that limit must stop further sourcing, combine the Source List with a Quota Arrangement and use the agreement target quantity as the quota item's maximum quantity.

Special exception: a Source List requirement or Source List block does not stop the separate Inventory Management function that can generate a purchase order automatically during goods receipt.

Material-group contracts

The Source List can act as an inclusion or exclusion control for a material-group contract item.

This is useful when one contract item covers a material group instead of naming every material explicitly.

Exclusion model

Most materials in the group may use the contract. Source List block entries identify the materials that must not be released against that contract item.

Inclusion model

Only materials for which the contract item appears in the Source List may use it. Other material masters receive a blocked-source result.

No material master

A free-text material without a material master cannot be blocked through the Source List for this material-group contract logic.

GUI path: change the contract in ME32K, select the material-group item, and use Item → Maintain Source List. The contract can also write Source List records during agreement maintenance.

Runtime use

Source determination combines several kinds of evidence.

A source list can point toward a source, while source determination can also consider info records, quota arrangements, and outline agreements according to the scenario.

01

Requirement

Start with material, plant, date, and procurement type.

02

Eligibility

Read the source list valid for the requirement date.

03

Control

Check fixed and blocked indicators and MRP relevance.

04

Source detail

Resolve supplier, info record, supplying plant, or agreement context.

05

Document

Verify which source was actually assigned to the requisition or purchase order.

Lead diagnosis

Find the owning layer before changing data.

A common failure is proving that a supplier exists but never proving that it is a valid source for this material, plant, and date.

Start here

Check material + plant → validity → source record → fixed/blocked/MRP flags → referenced source → resulting PR/PO.

Do not jump here

Do not assume the newest source-list record wins. The actual date, fixed or blocked state, and source-determination context matter.

record_voice_over

Assessment answer: “Source List is a time-dependent source-of-supply control for a material and plant. In manual source determination its validity is checked against the PR delivery date; in MRP it is checked against the requirements date. Fixed controls preference outside MRP, Block prevents use of a source, and MRP indicators 1 and 2 make an entry relevant for planning. I always separate source eligibility from Quota Arrangement allocation and from the supplier or agreement master data behind the entry.”
