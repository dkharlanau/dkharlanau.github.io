A shared operating rule

Usable by people.
Invocable by agents.

Repositories expose bounded machine-readable contracts and deterministic commands. Agent reasoning should consume those contracts rather than silently becoming the source of enterprise truth.

01 · DiscoverStart from the user problem and semantic owner.
02 · InspectValidate input, provenance, authority and boundaries.
03 · Execute safelyPrefer read-only, dry-run and deterministic operations.
04 · Return evidenceProduce structured output a person can review or retain.
