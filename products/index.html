Open enterprise transformation toolkit

Enterprise change,
made inspectable.

A family of small, composable products for turning transformation work into explicit contracts, relationship graphs, evidence, and reviewable artifacts. Each tool has one narrow job. Together they form a traceable delivery system.

Human-readable firstThe source remains understandable outside the tool.
DeterministicThe same input should produce the same decision or artifact.
Evidence over assertionsImportant outcomes can be inspected and reproduced.
Agent-compatibleAgents use bounded commands and machine-readable entry points.

Intent & contracts

Capture what a process, decision, transformation, or integration is supposed to do before execution makes it hard to see.

01 / PROCESS↗

Process as Code

Describe operating flows as executable, reviewable contracts and render the same source for different roles.

 02 / DECISIONS↗

Decision Tables as Code

Turn business rules into deterministic decisions with explicit facts, rule priority, and explainability traces.

 03 / MAPPING↗

Mapping as Code

Govern source-to-target transformations as contracts that can be validated, compiled, measured, and evidenced.

 04 / INTERFACES↗

Interface as Code

Keep an integration's contract, implementation binding, runbook, acceptance criteria, and evidence together.

Relationships & impact

Connect the contracts into graphs so teams can answer where a record came from, what depends on a change, and what a migration phase actually affects.

05 / LINEAGE↗

Data Relationship Map

Track record identity and lineage across source, extract, transformation, and target datasets.

 06 / TRANSFORMATION↗

Transformation Graph

Normalize mappings and interfaces into a dependency graph for impact analysis, role views, and assurance.

 07 / CHANGE↗

Enterprise Change Graph

Model processes, data, interfaces, roles, controls, and deployments around a change set to expose impact and readiness.

Assurance & execution

Turn readiness, reconciliation, cutover, project claims, and operations into explicit checks with inspectable evidence instead of status-by-spreadsheet.

08 / RECONCILIATION↗

Reconciliation as Code

Run reusable reconciliation rulepacks and produce evidence that explains whether transformed data is acceptable.

 09 / CUTOVER↗

Cutover Graph

Represent a cutover as a dependency graph with readiness gates, critical path, approvals, and immutable evidence.

 10 / EVIDENCE↗

Project Evidence Graph

Connect artifacts, controls, claims, quality gates, and evidence to reveal unsupported or stale project assertions.

 11 / OPERATIONS↗

SAP Agentic Operations

Expose operational checks and suggested actions through policy-gated, dry-run-first, evidence-producing capabilities.

Visual & learning

Make complex work easier to understand: one project turns structured material into useful business visuals; the other turns selected external signals into connected learning.

12 / VISUAL↗

Visual Workbench

A render-first workbench for repeatable diagrams, visual explanations, review loops, and presentation-ready artifacts.

 13 / INSIGHT↗

Signal → Insight

Turn selected feed items into concepts, explainers, source links, and a growing knowledge graph instead of an unread backlog.
A shared agent contract

Usable by people.
Invocable by agents.

The human pages explain the products. The repositories expose bounded agent entry points separately: a machine-readable manifest, repository instructions, deterministic commands, and explicit safety defaults.

01 · DiscoverRead the product manifest and supported capabilities.
02 · InspectValidate input and understand boundaries before acting.
03 · Execute safelyPrefer read-only, dry-run, and deterministic operations.
04 · Return evidenceProduce structured output a person can review or audit.

Small tools. One inspectable transformation system.

The toolkit is intentionally modular. Use one product for a concrete problem, or connect several through their files and adapters when traceability has to cross project boundaries.
